🤖 Simple AI Chat Bot in Python

This project is a basic console-based AI Chat Bot written in Python.
It interacts with users through text input and responds to predefined keywords such as greetings, Python, Data Science, and exit commands.

📌 Features

Greets the user politely

Answers basic questions about:

Python

Data Science

Takes user feedback (Yes / No)

Runs continuously until the user types an exit command

Beginner-friendly Python code

🛠️ Technologies Used

Python 3

Core concepts:

while loop

if-elif-else

input() and print()

String methods (lower())
